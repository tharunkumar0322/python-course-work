Def:
A function is a reusable block of code that performs a specific task.

Instead of writing the same code multiple times, we place it inside a function and call it
whenever needed.
Functions improve code reusability, readability, and maintainability.

Type of functions: Built-in Functions, User-defined Functions

Advantages of Functions:
 Code Reusability
 Better Code Organization
 Reduces Code Duplication
 Easier Debugging
 Easier Maintenance
 Improves Readability
 Makes Programs Modular
 Saves time
 

Type of arguments: 
1. Positional arguments
2. Keyword arguments
3. Default arguments
4. Variable length arguments
